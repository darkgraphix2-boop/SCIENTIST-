# LabBench

LabBench is a single-page interactive science dashboard for curious minds. It turns the scientific method into a tactile interface: choose a variable, tune its intensity, and run a playful projected-outcome simulation.

## Run locally

Open `index.html` in any modern browser. No build step or dependencies are required.

## What is included

- Responsive editorial landing page
- Interactive experiment controls for light, water, and soil nutrients
- Animated molecular-orbit hero illustration
- Accessible live result updates and mobile layout
